# NBA dataset citation and acquisition

Representative citation: Vladislav Shufinskiy, NBA WNBA play-by-play and shots data, Kaggle.
https://www.kaggle.com/datasets/brains14482/nba-playbyplay-and-shotdetails-data-19962021

The dataset card specifies Apache 2.0. The files used in this study were acquired through the same provider’s GitHub repository https://github.com/shufinskiy/nba_data (recorded commit e829d4678be1e075f99e5d41a1c5f97089be446b), including pbpstats_2023 and cdnnba_2023 archives, and NBA.com game data. The citation change does not indicate a new download, a byte-for-byte comparison with a Kaggle release, or direct authorization from NBA.
